Функция в Python определяется с помощью ключевого слова def, за которым следует имя функции и круглые скобки. Пример определения функции:

def say_hello():  # Функция, которая печатает приветствие
    print("Hello, World")

мы даем после def НАЗВАНИЕ
              Прикрепляем действие 

НАЗВАНИЕ  - вызывется действие которое прикреплено 


ПЕРЕДАЧА АРГУМЕНТА

def say_hello(name):
    print("Hello, " + name + "!")
    
say_hello("Alice")
В этом примере определена функция say_hello, которая принимает один аргумент name.
При вызове функции say_hello("Alice") аргумент "Alice" передается в функцию, и она выводит приветствие "Hello, Alice!"

Принцип бункера
Принцип бункера говорит о том, что внутрь функции нельзя "заглянуть" и получить значения локальных переменных.
Но функции могут читать значения глобальных переменных, но они не могут изменять их напрямую.
Вместоэтого они могут возвращать результаты своей работы с помощью возвращаемых значений


Чистая функция в программировании — это функция, которая при одинаковых входных данных всегда возвращает одинаковый результат и не имеет побочных эффектов, таких как изменение глобальных переменных.
Чистые функции полезны, потому что они предсказуемы и не зависят от состояния программы.


Выводы
Чистые функции являются предсказуемыми и не зависят от состояния программы.
Локальные переменные внутри функций не имеют отношения друг к другу и существуют только во время выполнения функции.
Изменение глобальных переменных внутри функций не рекомендуется. Чтение глобальных констант допустимо.
Функции должны быть детерминированы и возвращать одинаковый результат для одинаковых входных данных.

Методы
Методы очень похожи на функции, но существует одно важное отличие: они вызываются на определенном объекте с использованием точечной нотации.

some_object.method(args)

метод sort() - 
numbers = [3, 1, 2, 5, 4]
numbers.sort()  # sort метод сортировки списка
print(numbers)  # [1, 2, 3, 4, 5]

Именно меняет переменную, тогда как sorted просто возвращает новый отсортированный список, не изменяя исходный:
numbers = [3, 1, 2, 5, 4]
sorted_numbers = sorted(numbers)
print(sorted_numbers)  # [1, 2, 3, 4, 5]
print(numbers)  # [3, 1, 2, 5, 4]
